# کارت داده — inno-medical-telecare

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_telecare generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** ۶۰ بیمار × ۱۲۰ روز؛ ۳۰٪ بیماران افت تدریجی ۱۵ روزه؛ ۱۲٪ قرائت جاافتاده؛ آستانه‌ها نمونه‌اند و باید توسط پزشک معالج تعیین شوند.
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
