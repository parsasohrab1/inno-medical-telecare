# inno-medical-telecare

**مراقبت از راه دور بیماران مزمن**

> وضعیت: **TRL 4** — نمونه‌ی آزمایشگاهی با اعتبارسنجی اجزا روی **داده‌ی مصنوعی** (بدون داده‌ی بیمار). برای ارزیابی بالینی یا میدانی آماده نیست. ← [مستندات TRL](docs/TRL.md)

## نیاز شناسایی‌شده
دسترسی دشوار روستاها و پیگیری ناکافی دیابت و فشار خون.

## محصول
پایش از راه دور بیماران مزمن با هشدار به پزشک و بهورز.

## کاربران و ذی‌نفعان
بهورز، پزشک خانواده، شبکه‌ی بهداشت

## قابلیت‌های هدف
- ثبت قند و فشار توسط بیمار
- هشدار روند نگران‌کننده
- یادآوری دارو و ویزیت

## داده
قند، فشار، وزن، دارو. در مراحل اولیه فقط داده‌ی مصنوعی یا بی‌نام‌شده استفاده می‌شود.

## ریسک‌ها و محدودیت‌ها
فاصله‌ی دیجیتال؛ ایمنی هشدارها؛ حریم خصوصی.

## مسیر پیشنهادی
1. ✅ TRL 1 → 2: تعریف نیاز و معیار موفقیت (جدول معیارها در [docs/TRL.md](docs/TRL.md)).
2. ✅ TRL 3: نمونه‌ی آزمایشگاهی روی داده‌ی مصنوعی همراه با تست.
3. ✅ TRL 4: اعتبارسنجی اجزا در آزمایشگاه با تست‌های خودکار (CI روی هر push).
4. ⬜ TRL 5: اعتبارسنجی در محیط مرتبط با داده‌ی واقعی بی‌نام‌شده — نیازمندی‌ها در [docs/TRL.md](docs/TRL.md).

## یادداشت
این ریپو بخشی از مجموعه‌ی `inno-medical-*` برای دانشگاه‌های علوم پزشکی و وزارت بهداشت است. هیچ‌یک از خروجی‌ها جایگزین قضاوت بالینی نیست.

## راه‌اندازی سریع
```bash
pip install -r requirements.txt           # فقط numpy
export PYTHONPATH=src
python -m inno_medical_telecare generate --out data/sample # تولید داده‌ی مصنوعی (قطعی با seed)
python -m inno_medical_telecare validate                   # اجرای معیارهای TRL 4 روی ۳ seed
python -m inno_medical_telecare demo
python -m unittest discover -s tests -v
```

## آنچه پیاده‌سازی شده
قواعد مقادیر بحرانی (مسیر: پزشک)، هشدار روند با EWMA نسبت به خط پایه‌ی خود بیمار (مسیر: بهورز)، یادآوری قرائت‌های جاافتاده.
